# 🚀 Miltos Papageorgiou - Personal Portfolio

> Το προσωπικό μου portfolio και website, φτιαγμένο με Next.js για να παρουσιάζω τα projects, τις δεξιότητες και την εμπειρία μου.

## ✨ Features
- ⚡ **Next.js App Router:** Γρήγορη απόδοση και βέλτιστο SEO.
- 🎨 **Modern UI:** Καθαρός και minimal σχεδιασμός.
- 📱 **Responsive Design:** Πλήρως προσαρμοσμένο για κινητά και desktop.

## 🛠️ Tech Stack
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS (ή το αντίστοιχο που χρησιμοποιείς)
- **Deployment:** Vercel / Self-hosted
